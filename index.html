AppMédica

Creator and developer

Independent software project

  • I created AppMédica as an end-to-end application for practice administration: patient records, appointments, insurance follow-up, payments, and monthly reports.
  • The daily work is in the product: spreadsheet import, appointment closeout, claims follow-up, and data export.
  • The interface is React and TypeScript, the API is Python and FastAPI, and the data lives in PostgreSQL.
  • Authentication and role-based permissions let more than one person work in the same practice. Docker Compose runs it locally. Backend tests and the frontend build run in CI, and a script checks the core flows.
